### 📜 Current Side Quests

**[StardewValley Profit](https://github.com/paloma-guth/StardewValley-crops):** I love this game, but I love optimization even more. I got tired of guessing which crop would make me rich, so I built some Python scrapers to pull data from the wiki, threw it into custom objects, and ran statistical simulations to predict profits. Now I have code-backed financial strategies for a cozy farming simulator.<br><br>
**[Guild System DnD](https://github.com/paloma-guth/GuildSystem):** I wanted to deepen my skills in SQL and what better way to do that than uniting my studies with what I love? For a DM, keeping track of values, inventory, seasonal regional prices, and what each city size has in stock is incredibly tedious. So, I decided to build a backend API to automate all of that chaos.
